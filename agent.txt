Тестовое задание: Мини-сервис управления креативным отделом

Задача: разработать веб-сервис для постановки, отслеживания и контроля выполнения задач между медиабайерами и креативщиками.

Основной функционал:

• Роли: байер, креативщик, руководитель.
• Постановка задач: байер создаёт ТЗ через форму (оффер, GEO, тип креатива, количество, описание, референсы, приоритет, дедлайн).
• Kanban-доска: Новые → В работе → На проверке → Правки → Готово.
• Работа с задачами: креативщик самостоятельно берёт задачу, прикрепляет результат, байер принимает работу или отправляет на правки.
• Учёт времени: автоматически фиксируются время создания, взятия в работу, сдачи и завершения задачи, рассчитывается продолжительность выполнения.
• Учёт AI-расходов: креативщик указывает использованные AI-сервисы и количество потраченных кредитов по каждой задаче, включая правки.
• Аналитика: руководитель видит количество задач, загрузку сотрудников, среднее время выполнения, просрочки и расходы AI-кредитов по сервисам и исполнителям.

Технические требования:

• Современный, удобный интерфейс.
• Frontend + Backend + база данных.
• Сохранение истории действий и изменения статусов.
• Рабочая демоверсия с тестовыми пользователями и задачами.
• Стек технологий на выбор, использование AI приветствуется.

Результат: ссылка на работающий сервис, GitHub с исходным кодом и краткое описание использованных AI-инструментов, включая организацию работы нескольких агентов (если применялись).
